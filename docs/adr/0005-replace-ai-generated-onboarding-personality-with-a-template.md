# Replace AI-generated onboarding personality with a deterministic template

Onboarding used to call an LLM (`personalityGenerator.ts`) to write a "Soul Document" — several paragraphs of AI-authored prose about values, boundaries, and identity — from the user's name, use case, and tone, requiring a configured model and a visible generation wait before onboarding could finish. We replaced this with a fixed, deterministic Personality template built from the same inputs (name, use case, tone) plus a new Custom instructions field set separately in Personalization settings, rebuilt instantly whenever those settings change, with no model call involved. This trades away the richer, more personal prose an LLM can produce for a faster, provider-independent onboarding that behaves identically for every user and never fails due to a misconfigured or unavailable model.

**Consequences**: the `personality` AI feature and its model-routing entry are removed entirely, since nothing resolves a model target for it anymore. The underlying storage and system-prompt merge mechanism (`GlobalMemoryData.personality`, ai-core's memory merge in `loop.ts`) is unchanged — only what produces that string changed, from an AI call to instant templating from settings.
